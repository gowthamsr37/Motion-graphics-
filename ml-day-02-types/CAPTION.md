## Caption (paste this)

Predict a flat's price. Group a shop's customers. Teach a robot dog to walk. All three are machine learning, but each one learns in a completely different way 👇

🤖 DAY 2 / 100: THE 3 TYPES OF MACHINE LEARNING

1️⃣ SUPERVISED: learns from examples WITH the right answers (like practising with a solved question paper)
• Features = the inputs (area, bedrooms, city)
• Label = the answer (the price it sold for)
Two flavours:
🔢 Regression: the answer is a NUMBER (flat price in ₹ lakh, tomorrow's temperature)
🏷️ Classification: the answer is a CATEGORY (spam / not spam, loan repaid yes / no)
⚠️ The catch: labels are expensive. Someone has to tag every email, scan and transaction.

2️⃣ UNSUPERVISED: NO answers. The machine finds the structure on its own.
🛒 Clustering: plot customers by visits and spend → bargain hunters, loyal regulars, big spenders. Nobody named the groups; it found them.
🚨 Anomaly detection: a ₹48,000 card payment at 3 a.m. from abroad
🍞 What goes together: people who buy bread often buy butter

3️⃣ REINFORCEMENT: no answer key, no dataset. An agent learns by DOING.
🐕 Action → reward or penalty (step forward +1, fall over −10) → thousands of tries → the best moves
🏆 How a machine beat the world champion at Go, and how chatbots like ChatGPT are fine-tuned with human feedback

📋 Cheat sheet:
Have the right answers? → Supervised (it predicts)
No answers? → Unsupervised (it finds patterns)
Trial and reward? → Reinforcement (it learns actions)

## Poll (add while writing the caption)

- **Question:** Predicting how many days a patient will stay. Which type?
- **Options:** A Supervised: classification · B Supervised: regression · C Unsupervised · D Reinforcement

## Pinned comment (post a few hours later)

✅ Answer: B, supervised regression! The past records come with the answer (how many days each patient actually stayed), so it's supervised. And the answer is a NUMBER (2 days, 5 days, 11 days), so it's regression. If the question were "will this patient stay longer than a week, yes or no?", it would be classification. Did you get it? 👇
