A smoke alarm 🚨 can be wrong in two ways: it rings when there's no fire, or it stays silent during a real one 🔥 Statistical tests make the same two mistakes: TYPE 1 and TYPE 2 ERRORS.

📖 The definition, in simple words:
🟠 Type 1 error = a FALSE ALARM: rejecting the null when it was actually true
🟣 Type 2 error = a MISS: keeping the null when it was actually false

🔲 Picture all four outcomes: the null is true or false, and you reject it or keep it. Two boxes are correct; the other two are the errors.

🩺 A medical test:
• Telling a healthy person they're sick? Type 1 (false alarm)
• Telling a sick person they're healthy? Type 2 (a miss)

📊 Alpha and beta:
• The chance of a Type 1 error = ALPHA, usually 5%. When nothing's going on, about 1 test in 20 still raises a false alarm.
• The chance of a Type 2 error = BETA. 1 − beta is called POWER.

⚖️ The catch: the two errors trade off. A stricter test gives fewer false alarms but more misses. The way to reduce both? Collect more data.

🤔 Which is worse? It depends. Missing a disease can be deadly, so screening avoids Type 2 errors. Jailing an innocent person is a Type 1 error, so courts demand strong evidence.
