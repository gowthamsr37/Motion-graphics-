You've used machine learning about 12 times today 📱 Face unlock, spam filter, YouTube picks, Google Maps traffic. But what IS machine learning? Day 1 of 100 Days of Machine Learning starts now 👇

📒 DAY 1 / 100: WHAT IS MACHINE LEARNING?

❌ Normal programming: humans write the rules.
"IF the email says 'free money' → spam". Then spammers write "fr3e m0ney" and the rule breaks. You'd need millions of rules.

✅ Machine learning flips it:
Data + answers go in → the computer finds the rules by itself.
(10,000 emails, each labelled spam / not spam → it learns: weird spelling, lots of ₹₹₹, unknown senders…)

📖 Textbook definition: machine learning is a branch of AI where computers learn patterns from data, instead of being explicitly programmed. (Arthur Samuel, 1959: "the ability to learn without being explicitly programmed.")

🔁 How a machine actually learns:
Guess → measure the error → adjust → repeat. Do that enough times and the error becomes tiny.

🏠 What you get is a MODEL: a learned recipe. Give it a new house (1,500 sq ft) → it predicts the price.
• Features = the inputs (size)
• Label = the answer (price)

🧩 The 3 types:
1️⃣ Supervised: learns from examples WITH answers (spam / not spam)
2️⃣ Unsupervised: NO answers, finds hidden groups (types of customers)
3️⃣ Reinforcement: trial and error + rewards (mastering a video game)

🎯 Where it fits: AI ⊃ Machine Learning ⊃ Deep Learning (the tech behind ChatGPT)

## Poll (add while writing the caption)

- **Question:** A bank learns fraud from past transactions labelled fraud / not fraud. Which type?
- **Options:** A Supervised · B Unsupervised · C Reinforcement · D Not ML

## Pinned comment (post a few hours later)

✅ Answer: A, Supervised! Every past transaction comes with the answer (fraud or not fraud), so the model learns from labelled examples, exactly like the spam filter. If the bank had NO labels and just looked for weird transactions, that would be unsupervised (anomaly detection, coming later in the series). Did you get it? 👇
