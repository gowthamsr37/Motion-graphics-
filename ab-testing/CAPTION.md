A green Buy button or an orange one? 🟢🟠 Which makes more people buy? Don't guess. Test it. That's A/B TESTING.

📖 The definition, in simple words: show TWO VERSIONS to two RANDOM groups of users, then use a HYPOTHESIS TEST to decide if the difference is real.

🎲 The setup: split 10,000 visitors at random. 5,000 see the green button and 5,000 see the orange one. Random matters: the groups are alike in every other way, so only the button differs.

📊 The results after a week:
• Green (A): 400 purchases = 8%
• Orange (B): 460 purchases = 9.2%
Orange looks better. But is it real, or just luck?

🧪 The test: the null hypothesis says both buttons convert the same. If that were true, a gap this big would happen only about 3% of the time. So p = 0.03.

✅ The decision: 0.03 is below 0.05, so we reject the null. Orange wins: a 15% lift in purchases. Ship it!

⚠️ Three classic mistakes:
1️⃣ Stopping the test early the moment it looks good (peeking raises false alarms)
2️⃣ Skipping the plan for how many users you need
3️⃣ Changing many things at once
